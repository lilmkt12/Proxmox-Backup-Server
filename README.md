# proxmox-backup-server-lab

## Description
Ce projet consiste à mettre en place un **Proxmox Backup Server (PBS)** pour sauvegarder et restaurer des machines virtuelles (VM) et conteneurs hébergés sur un hyperviseur **Proxmox VE**.  
L’objectif était d’automatiser les sauvegardes et d’assurer la continuité de service en cas de panne.

## Objectifs
- Installer et configurer un serveur **Proxmox Backup Server**.  
- Connecter PBS à un serveur **Proxmox VE**.  
- Sauvegarder automatiquement des VM et des conteneurs.  
- Tester la restauration complète d’une VM.  

## Outils utilisés
- Proxmox VE  
- Proxmox Backup Server (PBS)  
- Stockage réseau (NAS)  
- VM et conteneurs Linux/Windows

## Résultats
- Connexion réussie entre PBS et Proxmox VE.  
- Sauvegarde planifiée et restauration d’une VM validées.  
- Solution fonctionnelle et prête pour un usage en environnement réel.
